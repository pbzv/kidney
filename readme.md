# رَفِيقُ الكِلَى

تطبيق ويب يهدف إلى مساعدة مرضى الكلى على متابعة استهلاك السوائل اليومية، تنظيم المواعيد الطبية، والالتزام بالعلاج، من خلال واجهة بسيطة ونظام تذكير ذكي.

---
## ✨ المميزات

- تتبع كمية السوائل اليومية (مع شريط تقدم دائري)
    
- إعادة تعيين تلقائي للكمية عند منتصف الليل
    
- نظام تذكير بشرب السوائل
    
- عرض موعد الجلسة القادمة
    
- عرض الوصفة الطبية (الدواء والجرعة)
    
- ملاحظات الطبيب
    
- حفظ البيانات محليًا باستخدام LocalStorage
    

---
## 🛠️ التقنيات المستخدمة

- HTML5
    
- CSS3 (Flexbox + Grid + Animations)
    
- JavaScript (ES Modules)
    
- Node.js (Express.js)
    
- LocalStorage API
    
- Notifications API

## ▶️ كيفية التشغيل

1. قم بعمل **Clone** أو تحميل المشروع من GitHub
    
2. تأكد من تثبيت Node.js
    
3. قم بتثبيت الحزم المطلوبة:

```bash
npm install express
```

4. افتح ملف `server.js` وعدّل الإعدادات إذا لزم:

```js
const IP = "0.0.0.0";
const PORT = 5000;
```

5. شغّل السيرفر:

```bash
node server.js
```

6. افتح المتصفح وانتقل إلى:

```
http://127.0.0.1:5000
```
